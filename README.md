# 🗄️ Project Database Manager

Удобный инструмент на Python для инициализации и управления реляционной базой данных SQLite. Проект разработан для структурирования информации о ваших проектах, статусах их разработки и используемых технологиях (стеке).

## 🚀 Основные возможности

* **Автоматическое создание таблиц**: быстрая генерация схемы БД с внешними ключами.
* **Управление статусами**: отслеживание жизненного цикла проекта (от проектирования до завершения).
* **Привязка навыков**: связь проектов с используемыми технологиями через промежуточную таблицу.
* **Масштабируемость**: встроенный метод для динамического обновления структуры (добавление фото).
